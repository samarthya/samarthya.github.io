# Security policy

This repository builds [samarthya.github.io](https://samarthya.github.io), a personal portfolio site. It is a
static site rendered with Quarto by GitHub Actions and served by GitHub Pages; it has no server-side code,
logins, forms or database.

## Reporting a problem

If you find a security problem with the site or this repository (for example a secret committed by mistake,
personal data that shouldn't be public, or a way to change what the site serves), please report it privately:

- **Preferred:** GitHub's [private vulnerability reporting](https://github.com/samarthya/samarthya.github.io/security/advisories/new)
- **Or email:** admin@samarthya.me

Please don't open a public pull request for security reports.

## What to expect

This is a one-person project, so replies are best effort, usually within a few days. There is no bug bounty.

## Scope

In scope: this repository, its GitHub Actions workflow, and the published site at samarthya.github.io.
Out of scope: the blog at [samarthya.me](https://samarthya.me) (see its own
[security policy](https://github.com/samarthya/blog.samarthya.me/blob/main/SECURITY.md)), and third-party
services the site links to.
